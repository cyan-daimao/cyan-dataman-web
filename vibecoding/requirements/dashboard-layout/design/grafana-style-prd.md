# BI 看板编辑器/查看器 — Grafana 风格交互方案

> 数据模型保持不变：筛选框也是 Chart，级联关系存在 layout 表（cascadeFrom）。只改 UI 交互和视觉。

---

## 一、当前问题

1. **编辑器左侧图表库是表格形式** — 像后台管理，不像 BI 工具
2. **画布上只有文字占位符** — 没有面板预览效果
3. **筛选框散落在画布各处** — 查看时不易发现和使用
4. **没有顶部统一控制栏** — Grafana 顶部有时间范围、刷新、变量筛选器
5. **属性面板太简陋** — 没有 Tab 分组，所有配置堆在一起
6. **面板没有操作菜单** — 不能像 Grafana 那样点击 ⋮ 编辑/复制/删除

---

## 二、Grafana 核心交互借鉴

### 2.1 面板（Panel）概念

Grafana 中每个可视化单元叫 Panel，我们的"图表"对应 Panel：
- 每个 Panel 有标题栏（可拖拽 + 操作菜单）
- Panel 有圆角、阴影、背景色
- Panel 支持拖拽调整位置、拖拽右下角调整大小
- 选中 Panel 时边框高亮

### 2.2 顶部控制栏（Dashboard Toolbar）

Grafana 顶部固定一排控制元素：
- 看板名称（可编辑）
- 时间范围选择器（DatePicker.RangePicker）
- 刷新按钮
- 自动刷新频率下拉
- 变量/筛选器行（Variables Row）

**我们的方案**：把筛选框图表统一提取到顶部渲染，像 Grafana 的 Variables 一样横向排列。

### 2.3 侧边栏属性面板（Panel Options）

Grafana 选中 Panel 后右侧弹出属性面板，分 Tab：
- **常规**（General）：标题、描述、透明背景
- **查询**（Queries）：数据源和查询配置
- **可视化**（Visualization）：图表类型和配置
- **覆盖**（Overrides）：字段级配置

**我们的方案**：
- **布局**（Layout）：x/y/w/h
- **显示**（Display）：标题、边框、背景色、透明模式
- **联动**（Cascade）：cascadeFrom 多选配置

## 三、DashboardEditor 重构方案

### 3.1 整体布局

```
┌─────────────────────────────────────────────────────────────────┐
│  [看板名称 ▼]  [📅 时间范围] [🔄 刷新] [保存] [预览] [设置]       │  ← 顶部工具栏
├─────────────────────────────────────────────────────────────────┤
│  ┌──────────┐  ┌────────────────────────────────────┐  ┌──────┐ │
│  │          │  │                                    │  │      │ │
│  │ 组件库   │  │         画 布 (12列网格)            │  │ 属性 │ │
│  │ (可折叠) │  │                                    │  │ 面板 │ │
│  │          │  │  ┌────────┐  ┌────────┐           │  │ (可折│ │
│  │ • 图表   │  │  │ Panel 1│  │ Panel 2│           │  │ 叠)  │ │
│  │ • 筛选框 │  │  │ [BAR]  │  │ [LINE] │           │  │      │ │
│  │          │  │  └────────┘  └────────┘           │  │      │ │
│  │          │  │                                    │  │      │ │
│  └──────────┘  └────────────────────────────────────┘  └──────┘ │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 组件库（左侧）

**改造前**：表格形式，点击"添加"按钮

**改造后**：
- 卡片式列表，每个图表显示名称 + 类型图标 + 缩略预览
- 支持拖拽到画布（drag & drop）
- 搜索框过滤
- 分类 Tab：全部 / 数据图表 / 筛选框
- 筛选框区域单独分组，用不同颜色标识

### 3.3 画布（中间）

**改造前**：文字占位符 + 简单的拖拽

**改造后**：
- 12列网格，背景浅灰色
- 每个 Panel：
  - 标题栏：拖拽手柄 + 标题 + 类型图标 + ⋮ 操作菜单（编辑/复制/删除）
  - 内容区：显示图表类型的大图标 + 名称（类似 Grafana 的占位态）
  - 选中态：蓝色边框高亮（#4F6DF5）
  - 调整大小手柄：右下角小三角，hover 显示
- 空画布提示：虚线框 + "拖拽图表到此处"

### 3.4 属性面板（右侧）

**改造前**：所有配置堆在一个 Card 里

**改造后**：
- 可折叠的侧边栏（宽度 320px）
- Tab 切换：
  - **布局**：x, y, w, h（4个输入框并排）
  - **显示**：标题开关、边框样式、背景色、透明模式
  - **联动**：cascadeFrom 多选输入框（antd Select mode="multiple"）
- 未选中 Panel 时显示提示："点击画布中的面板进行配置"

## 四、DashboardViewer 重构方案

### 4.1 整体布局（Grafana 风格）

```
┌─────────────────────────────────────────────────────────────────┐
│  [看板名称]                    [📅 时间范围] [🔄 刷新] [编辑]     │  ← 顶部工具栏
├─────────────────────────────────────────────────────────────────┤
│  ┌──────────┐ ┌──────────┐ ┌──────────┐                        │  ← 筛选栏
│  │ 地区 ▼   │ │ 时间 ▼   │ │ 渠道 ▼   │  [重置]               │     (筛选框图表)
│  └──────────┘ └──────────┘ └──────────┘                        │
├─────────────────────────────────────────────────────────────────┤
│  ┌──────────────────┐ ┌──────────────┐ ┌──────────────┐        │  ← 画布
│  │   Panel 1        │ │   Panel 2    │ │   Panel 3    │        │
│  │   [BAR Chart]    │ │   [LINE]     │ │   [TABLE]    │        │
│  └──────────────────┘ └──────────────┘ └──────────────┘        │
│  ┌──────────────────────────────────────────┐                  │
│  │              Panel 4                       │                  │
│  │              [AREA Chart]                  │                  │
│  └──────────────────────────────────────────┘                  │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 筛选栏（关键改进）

**核心决策**：查看器加载时，把 chartRefs 中所有筛选框类型的图表提取出来，统一渲染在画布上方的筛选栏中。

- 筛选栏背景：浅灰色，与画布区分
- 每个筛选框：label（图表名称）+ 控件（Select/DatePicker）
- 多选支持去除（×）
- 右侧有"重置"按钮，一键清空所有筛选
- 筛选框不在画布中重复渲染（避免混乱）

**级联逻辑不变**：
- 筛选框值变化 → 查 cascadeFrom → 合并 filters → 重新 execute → 画布中对应 Panel 刷新

### 4.3 画布面板样式

- 圆角 4px（Grafana 风格）
- 轻微阴影 `box-shadow: 0 1px 2px rgba(0,0,0,0.1)`
- 标题栏：底部边框分隔
- 加载态：面板内居中 Spin
- 错误态：红色提示文字

## 五、数据模型影响

| 数据模型 | 是否变更 | 说明 |
|---------|---------|------|
| Chart 表 | ❌ 不变 | 筛选框图表仍是 Chart |
| Dashboard 表 | ❌ 不变 | chartRefs 结构不变 |
| cascadeFrom | ❌ 不变 | 仍存于 chartRefs 中 |
| 筛选框参与布局 | ✅ 调整 | 编辑器中参与布局，查看器中提取到顶部 |

**关键说明**：筛选框在编辑器中仍然放在画布上（方便拖拽布局），但在查看器中统一提取到顶部筛选栏渲染。这是纯前端 UI 层的调整，不影响后端数据存储。
