# 图表管理中心与筛选框创建 — 产品需求文档

## 一、背景与问题

### 1.1 当前现状
- 系统已支持 7 种数据图表（TABLE/NUMBER/BAR/LINE/PIE/SCATTER/AREA）的创建、编辑、执行
- 系统已支持 4 种筛选框图表类型（FILTER_SELECT/FILTER_MULTI/FILTER_DATE/FILTER_DATE_RANGE）的后端枚举和看板渲染
- **缺失**：ChartAnalyzer（图表分析器）不支持创建筛选框图表，chartTypeOptions 中无 FILTER 类型
- **影响**：用户在看板编辑器中无法从组件库找到可用的筛选框图表，因为根本没有创建入口

### 1.2 用户痛点
1. 看板编辑器左侧「筛选框」Tab 永远显示 0 个可用图表
2. 用户不知道去哪里创建筛选框图表
3. 现有「图表分析」页面列表混杂（数据图表 + 筛选框混在一起），没有分类管理

---

## 二、竞品调研结论

| 产品 | 筛选器管理方式 | 创建位置 | 与看板关系 |
|------|--------------|---------|-----------|
| **Grafana** | Variables（变量），非独立对象 | Dashboard Settings → Variables | 看板级别配置，不占用面板 |
| **Metabase** | Dashboard Filter，非独立对象 | 编辑看板 → Add Filter | 看板级别配置，不占用面板 |
| **Superset** | Native Filter，非独立对象 | 编辑看板 → Add Filter | 看板级别配置，不占用面板 |
| **Quick BI** | 筛选器图表，**独立对象** | 图表创建 → 选择「筛选器」类型 | 作为特殊图表参与看板布局 |
| **观远数据** | 卡片式，独立对象 | 卡片创建 → 选择「筛选」类型 | 作为特殊卡片参与看板 |

**关键结论**：
- 国外产品（Grafana/Metabase/Superset）倾向于「看板级筛选器」，不独立管理
- 国内产品（Quick BI/观远）倾向于「筛选器图表」，作为独立对象管理
- **我们已采用「筛选框图表」模型**（FILTER_* 是 ChartType 的一种），应延续此路线，在图表管理中心提供创建入口

---

## 三、方案设计

### 3.1 核心决策

| 决策点 | 方案 | 理由 |
|--------|------|------|
| 筛选框是否作为独立图表对象 | **是**，延续现有设计 | 后端 ChartType 已扩展 FILTER_*，已有 execute 逻辑，改动最小 |
| 创建筛选框的入口 | **图表分析页面 + 看板编辑器快捷创建** | 双入口，兼顾管理中心和便捷性 |
| 图表列表是否分类展示 | **是**，分「数据图表」和「筛选框」两类 | 避免列表混杂，提升查找效率 |

### 3.2 整体架构

```
图表管理中心（/bi/chart）
  ├── 顶部：Tab 切换（数据图表 | 筛选框）
  ├── 搜索框
  ├── 列表：按 Tab 过滤展示
  ├── 新建按钮：根据当前 Tab 新建对应类型
  │     ├── 数据图表 → ChartAnalyzer（现有）
  │     └── 筛选框 → FilterCreator（新增）
  └── 操作：编辑 / 删除 / 执行预览

看板编辑器（/bi/dashboard/edit）
  ├── 左侧组件库
  │     ├── Tab：图表 | 筛选框
  │     ├── 列表展示
  │     └── 底部：「+ 新建筛选框」快捷按钮
  └── 点击后直接创建并添加到画布
```

## 四、功能设计

### 4.1 图表分析页面重构（图表管理中心）

#### 4.1.1 页面布局

```
┌─────────────────────────────────────────────────────┐
│  [数据图表] [筛选框]        [搜索...]    [+ 新建图表] │  ← 顶部 Tab + 搜索 + 新建
├─────────────────────────────────────────────────────┤
│  ┌────────┐ ┌────────┐ ┌────────┐                  │
│  │ 图表1   │ │ 图表2   │ │ 图表3   │  ← 卡片式列表    │
│  │ BAR    │ │ LINE   │ │ TABLE  │                  │
│  └────────┘ └────────┘ └────────┘                  │
│                                                     │
│  分页                                               │
└─────────────────────────────────────────────────────┘
```

#### 4.1.2 Tab 切换
- **数据图表**：展示 chartType 为 TABLE/NUMBER/BAR/LINE/PIE/SCATTER/AREA 的图表
- **筛选框**：展示 chartType 为 FILTER_SELECT/FILTER_MULTI/FILTER_DATE/FILTER_DATE_RANGE 的图表
- 切换时列表重新过滤，分页重置

#### 4.1.3 卡片信息
- 图表名称
- 类型标签（带颜色区分：数据图表蓝色系 / 筛选框绿色系）
- 分析类型（指标平台 / 数据集）
- 创建时间
- 操作按钮：编辑 / 删除 / 预览执行

#### 4.1.4 新建按钮行为
- 当前在「数据图表」Tab：点击跳转 ChartAnalyzer 新建数据图表
- 当前在「筛选框」Tab：点击打开 FilterCreator 弹窗创建筛选框

### 4.2 筛选框创建器（FilterCreator）

#### 4.2.1 弹窗表单

```
┌────────────────────────────────────────┐
│  新建筛选框                              │
├────────────────────────────────────────┤
│  筛选框名称 *                            │
│  [________________________]            │
│                                        │
│  筛选类型 *                              │
│  [单选下拉框 ▼]                         │
│    - 单选下拉框 (FILTER_SELECT)         │
│    - 多选下拉框 (FILTER_MULTI)          │
│    - 日期选择器 (FILTER_DATE)           │
│    - 日期范围 (FILTER_DATE_RANGE)       │
│                                        │
│  分析类型 *                              │
│  (•) 指标平台    ( ) 数据集              │
│                                        │
│  选择维度 *                              │
│  [请选择维度 ▼]                         │
│    - D_REGION (地区)                    │
│    - D_DATE (日期)                      │
│    - D_CHANNEL (渠道)                   │
│                                        │
│  描述                                    │
│  [________________________]            │
│                                        │
│              [取消]  [确定]             │
└────────────────────────────────────────┘
```

#### 4.2.2 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 筛选框名称 | 是 | 显示在看板中的名称 |
| 筛选类型 | 是 | 决定渲染为 Select/DatePicker/RangePicker |
| 分析类型 | 是 | METRICS（指标平台）或 DATASET（数据集） |
| 选择维度 | 是 | 指标模式下从维度库选择；数据集模式下从数据集字段选择 |
| 描述 | 否 | 备注说明 |

#### 4.2.3 DSL 生成

创建时自动组装 `MetricBiAnalysisCmd`：
```json
{
  "chartType": "FILTER_MULTI",
  "metrics": [],
  "dimensions": [{ "dimCode": "D_REGION", "alias": "地区" }],
  "filters": [],
  "orders": [],
  "limitValue": 1000
}
```

后端 execute 时返回该维度的 distinct values。

### 4.3 看板编辑器快捷创建

#### 4.3.1 左侧组件库改造

```
┌─────────────────┐
│ 组件库           │

│ [全部] [图表] [筛选框] │

│                 │
```

- 弹出 FilterCreator 弹窗

- 自动执行获取选项列表

## 五、交互流程

### 流程1：在图表管理中心创建筛选框

```
1. 用户进入「图表分析」页面
2. 点击「筛选框」Tab
3. 点击「+ 新建筛选框」
4. 填写表单（名称/类型/维度）
5. 点击确定 → 调用 chartApi.create
6. 筛选框创建成功，出现在列表中
7. 用户进入看板编辑器，从组件库添加该筛选框
```

### 流程2：在看板编辑器中快捷创建筛选框

```
1. 用户进入看板编辑器
2. 左侧组件库点击「+ 新建筛选框」
3. 填写表单（名称/类型/维度）
4. 点击确定 → 调用 chartApi.create
5. 创建成功后自动添加到画布（自动计算不重叠位置）
6. 自动执行获取选项列表，渲染为筛选控件
```

## 六、涉及的后端接口

**无新增后端接口**。复用现有接口：

| 接口 | 说明 |
|------|------|
| `POST /api/v1/charts` | 创建筛选框（chartType 传 FILTER_*） |
| `GET /api/v1/charts` | 列表查询（支持按 chartType 筛选） |
| `POST /api/v1/charts/{id}/execute` | 执行筛选框获取选项列表 |

**可能需要后端微调**：
- `GET /api/v1/charts` 支持按 chartType 筛选（当前参数中没有 chartType 筛选，需要确认是否支持）
- 维度列表接口（指标模式下获取可用维度）
