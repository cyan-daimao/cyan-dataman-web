# 前端需求文档：数据库表配置与同步中心

## 1. 功能概述
在在@src/pages/metadata中，现有的左侧导航栏中新增“业务数据库”模块(和元数据，数据监控平级)和对应的二级模块。该模块允许用户可视化管理数据库表结构，对比测试与生产环境的差异，发起同步审批，并管理 CDC（变更数据捕获）状态。

## 2. 导航与路由
-   **菜单位置**：左侧侧边栏
-   **菜单名称**：业务数据库
-   **二级菜单**：1.数据源 2.数据库 3表结构
-   **图标**：Database / Cylinder
-   **路由路径**： 在@src/router/index.ts 中使用这个路由
   {
    path: "business-ds",
    element: <Metadata/>,
    children: [
    {
    path: "",
    element: <div></div>
    },]
    },

## 3. 页面结构与交互设计

页面主要分为两个视图：**表列表视图** 和 **表详情/编辑视图**。

### 3.1 表列表视图
这是进入模块后的默认页面，用于展示所有已配置的表。

#### 核心组件
-   **顶部操作栏**：
    -   **搜索框**：支持按表名搜索。
    -   **新建表按钮**：点击后进入“新建表模式”。
-   **数据表格**：
    -   **列定义**：
        -   表名
        -   描述
        -   CDC 状态：开关组件，显示当前是否在大数据平台注册。
        -   环境状态：标签显示（例如：✅ 生产已同步 / ⚠️ 待发布 / ⚠️ 测试落后）。
        -   最后更新时间
        -   操作列：[编辑] [同步历史] [删除]

### 3.2 表详情/编辑视图
点击“新建”或“编辑”时进入此视图。这是一个分屏或抽屉式设计。

#### 左侧：表结构定义
-   **基本信息**：输入框（表名、引擎类型、字符集、备注）。
-   **字段管理**：
    -   动态表格，支持增删改行。
    -   **列**：字段名、数据类型、长度、是否主键、是否非空、默认值、注释。
    -   **交互**：支持拖拽排序（可选），点击“+”号添加新字段。
-   **索引管理**：
    -   类似字段管理的动态表格（索引名、类型、包含字段）。

#### 右侧：预览与操作
-   **DDL 预览**：实时生成 SQL 语句（只读文本域）。
-   **环境对比面板**：
    -   **测试环境**：显示当前测试库的实际结构（只读）。
    -   **生产环境**：显示当前生产库的实际结构（只读）。
    -   **Diff 视图**：如果存在差异，高亮显示差异行（红色删除，绿色新增）。
-   **底部操作栏**：
    -   **保存草稿**：仅保存到本地配置库。
    -   **同步到生产**：
        -   点击后弹出确认模态框。
        -   显示即将执行的 DDL 语句。
        -   显示 CDC 影响提示（例如：“检测到该表开启了 CDC，同步后将自动更新大数据平台配置”）。
        -   确认后触发审批流。

## 4. 关键交互流程

### 4.1 同步与审批流程
1.  用户点击“同步到生产”。
2.  前端调用 `POST /api/table-config/publish`。
3.  **状态变更**：列表页该表状态变为“审批中”。
4.  **审批回调**：
    -   若审批通过：前端通过轮询或 WebSocket 收到通知，状态变为“同步成功”，并自动刷新生产环境结构快照。
    -   若审批拒绝：状态变为“已拒绝”，显示拒绝理由。

### 4.2 CDC 感知反馈(不做)
-   在编辑页面，如果用户开启了“CDC 启用”开关：
    -   界面显示一个 Info 提示：“开启后，表结构变更将自动同步至大数据平台。”
-   在同步成功后的通知中：
    -   显示步骤状态：
        1.  ✅ 生产数据库执行成功
        2.  ✅ 大数据平台元数据更新成功
